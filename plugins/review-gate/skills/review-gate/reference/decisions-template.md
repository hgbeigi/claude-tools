# Decisions

One line per decision that later work must not quietly reverse. Newest at the bottom. The reviewer quotes from this file under condition 2.

Fill it in as you decide things. Keep each line short: the date, the decision, and the reason.

| Date | Decision | Reason | Replaces |
|---|---|---|---|
| YYYY-MM-DD | Example: monthly reports are saved as PDF, not Word. | Easier to share and print. | none |
| YYYY-MM-DD | Example: one project per folder; no shared scratch files. | Two projects overwrote each other's notes. | none |

To change a decision, add a new line that names the one it replaces. Do not edit the old line.
