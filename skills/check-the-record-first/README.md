# Check the record first

Claude searches your own notes and files before it states a fact about your life or asks you a question, and names the source beside each fact.

## Try it

1. When does my car insurance renew? It's in my notes.
2. Why are you asking me my policy number? Check first.
3. Fill in this form from what we already have on file, and list what is missing.

## Sample data

No sample data needed: it searches the notes folder you name.

## Install

```
/plugin marketplace add hgbeigi/claude-tools
/plugin install check-the-record-first@hgbeigi-tools
```

Privacy: nothing is collected or sent anywhere. See [PRIVACY.md](../../PRIVACY.md).
