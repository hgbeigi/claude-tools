# Correction to skill

When you correct Claude, the correction becomes a dated rule in the skill, agent or instruction file that caused the mistake, in the same session, and Claude says where it went.

## Try it

1. That's wrong: dates in my reports are always written like 2 November 2026. Remember this.
2. I told you before not to open the browser for this. Why didn't you check the file first?
3. From now on, ask before you delete anything in the drafts folder.

## Sample data

No sample data needed: it works on your own instruction files.

## Install

```
/plugin marketplace add hgbeigi/claude-tools
/plugin install correction-to-skill@hgbeigi-tools
```

Privacy: nothing is collected or sent anywhere. See [PRIVACY.md](../../PRIVACY.md).
