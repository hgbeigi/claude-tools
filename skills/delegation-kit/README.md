# Delegation kit

Two skills for working with helper agents: `agent-brief` (how to brief a helper so it finishes without asking, and how many to send) and `agent-report` (the report it hands back, and the read-back before anything is called done).

## Try it

1. Send three agents to compare these options, one per option.
2. Split this up: one helper reads the docs, one reads the code.
3. Is it done? Did you check what the helper wrote?
