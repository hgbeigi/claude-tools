# Known limits

One register of what your tools cannot do and the route that works instead, read before Claude says "impossible", so nothing is retried blindly and nothing is given up after one look.

## Try it

1. Is there any way to read that site? It refused last time.
2. Why can't you open this file? Check the known limits first.
3. Add this to the limits: the export button only works in the desktop app.

## Sample data

No sample data needed: the register starts empty and grows with your own findings.

## Install

```
/plugin marketplace add hgbeigi/claude-tools
/plugin install known-limits@hgbeigi-tools
```

Privacy: nothing is collected or sent anywhere. See [PRIVACY.md](../../PRIVACY.md).
